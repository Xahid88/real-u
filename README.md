# Real U - AI Fact Checker Extension 🛡️

**Real U** is a browser extension that helps combat misinformation by analyzing online media (text, photos, videos) in real-time. It uses an AI backend powered by Gemini to verify context, detect AI generation, and provide an authenticity score for any webpage you visit.

## Features ✨
- **Instant Analysis**: Click to scan the active web page and extract text and media content.
- **Authenticity Score**: Get a fast, accurate 0-100% reliability score for the content you are reading.
- **Deepfake & AI Detection**: See metrics on whether the content was likely generated by AI.
- **Real-Time Context Matching**: Cross-references text with established facts to detect inconsistencies.
- **Caching System**: Fast responses for previously scanned URLs to save API costs and reduce wait times.

## How to Install the Extension (Local Development) 🚀

1. **Clone this repository** (or download as ZIP and extract).
2. Open Google Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** (toggle switch in the top right corner).
4. Click **Load unpacked** and select the root directory of this project (`real-u`).
5. Pin the "Real U" extension to your Chrome toolbar for easy access.

## Setting up the Backend Server 🖥️

For the extension to perform AI analysis, you must run the local Node.js backend server.

1. Open your terminal and navigate to the `server` folder:
   ```bash
   cd server
   ```
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file inside the `server` directory and add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_actual_api_key_here
   PORT=3000
   ```
   *(Note: If you don't provide an API key, the server will fall back to using simulated/mock data for testing.)*
4. Start the server:
   ```bash
   npm start
   ```
5. You should see `Real U Server running on http://localhost:3000`. The extension is now ready to use!

## Tech Stack 🛠️
- **Frontend / Extension**: HTML, CSS, Vanilla JavaScript, Chrome Extension APIs
- **Backend Server**: Node.js, Express.js
- **AI Model**: Google Gemini 2.5 Flash (`@google/genai`)
- **Caching**: Node-Cache (in-memory)
